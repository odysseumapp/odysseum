## The line

The blank atlas page → the palm-sized map → the bell tower on the wrong side → the photograph → the northern shore.

## The rule of the thread

The map changes first. The island catches up. Mara notices the map, then the island, and only late in the book does she understand the order matters.

## Danger

It is easy to make this a puzzle. It is a grief.
