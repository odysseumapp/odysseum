## Forgetting

A place nobody has thought about in a long while begins to thin. Paths grow over first, then walls, then the ground itself. Nan’s ledger records the last person to mention it; when that name is crossed out, the place has a season left.

## Remembering

A place remembered too hard, or by two people in different ways, moves. It goes where the stronger memory puts it. Deliberate remembering (Elin’s daily rounds) holds a place still but costs the rememberer something.

## Why the map moves first

The palm-sized map is drawn in Mara’s childhood handwriting. It is a record of *her* memory, and her memory changes before she notices. The island follows the strongest map on it.
